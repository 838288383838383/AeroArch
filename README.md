# AeroArch

**Frutiger Aero** themed Arch Linux distribution.

A love letter to the glossy, translucent, bubbly Windows Vista / Windows 7 Aero aesthetic.

## Features
- KDE Plasma 6 with Aero glass effects
- Custom icons, cursors & colors
- Glossy Plymouth boot
- Nostalgic yet modern

## Installation

```bash
git clone https://github.com/838288383838383/AeroArch.git
cd AeroArch
chmod +x scripts/*.sh
./scripts/post-install.sh
```
